# 不调用云端模型的本地搜索

此模块把代码扫描、下载指定文档、正文提取、关键词匹配、排序和缓存放在运行程序的设备上。使用 Python 标准库；没有 LLM、embedding 或云端搜索 API。模型若调用工具并阅读搜索结果，调用描述与返回片段仍会占用模型 token。

## 使用

在仓库根目录运行：

```bash
python3 -m flowcache search "cache expiry validation" --root ./flowcache --top-k 4 --max-chars 2400
```

本地代码搜索不联网；可以直接用中文词语查询中文文档。返回文件、所在行区间、匹配词、原文片段与计量。行区间是候选片段的来源范围，可能大于截短后的展示文本。

抓取你指定的网页，并与代码一起检索：

```bash
python3 -m flowcache search "argument parser" --root ./flowcache \
  --url https://docs.python.org/3/library/argparse.html \
  --top-k 4 --max-chars 2400
```

网络请求从运行 Python 程序的设备发起，不会调用 OpenAI 搜索或模型。页面缓存默认保留 1 小时，位于所选 root 的 `.flowcache/web-search` 中；再次查询有效缓存不下载。网页失败时继续返回本地结果，同时明确记录错误；不会自动切换到收费服务。HTTP 重定向不自动跟随，应直接提供最终页面 URL。

## 在编码流程中使用

可以让有终端执行能力的编码助手先运行上面的命令，仅阅读输出片段，需要时再读取具体文件的相关部分。无需让模型阅读整份仓库或每篇全文。当前版本提供 CLI，**没有自动修改全局 Codex 配置或替换其内置搜索工具**。

为避免自己把大结果重新送给模型，使用 `--max-chars` 限制片段正文总量（不含 JSON 元数据）；默认 4000 字符。字符不是 token，中文、代码、路径的 token 比率不同。CLI 不依赖 tokenizer，不能据此直接声称节省了多少真实账单。

## 边界

- 本版检索本地代码库及明确提供的文档 URL；没有全网关键词发现，也不提供云端语义推理。全网发现需要另接搜索服务或自建搜索索引。
- 排序为词法 BM25 风格计算，中文使用相邻双字；它可能漏掉同义表达。没有命中时返回空列表，不伪造答案。
- 默认跳过隐藏文件、符号链接、依赖和生成目录；单文件上限 512 KB，最多 2000 文件 / 32 MB 本地文本。只对你选择的可信目录运行；这些规则不是全面的机密扫描器。
- 每次最多 8 个明确文档 URL，每篇下载上限 1 MB。网络字节指标只统计成功返回的正文；失败传输也可能使用流量。
- 返回文本被标注为不可信来源数据，不能当成新的助手指令。关键词提取不是提示注入防护的完整替代方案。
- 在你的电脑上运行才使用你的电脑网络；当前聊天执行环境的网络不等于 iPad 网络。iPad 原生浏览器适配未实现。

测试覆盖本地零网络路径、字符预算、中文匹配、文件删除失效、符号链接排除、真实 HTTP 首次抓取与再次缓存命中、抓取错误回退及非 HTTP URL 拒绝。

## 本次验证

2026-09-16：原有 22 项加新增 7 项，共 29 项测试通过。HTTP 下载与缓存通过真实环回 HTTP 服务验证。直接抓取公网 Python 文档时，本执行环境 DNS 解析失败，因此不声称公网下载已验收，更未使用 iPad 网络。

对 `flowcache/` 的查询 `cache expiry validation`，10 个文本文件完整内容带路径包装共 17,269 个 o200k_base token；返回的完整 JSON（包含片段、来源、计量等元数据）共 970 token。相对全量发送，单次上下文规模减少约 94.38%。这不是实际 Codex 会话账单，未测量真实模型输入、输出、推理 token 或最终编码质量。另一查询、预算或语料可能有完全不同的效果。

测量数据见 `examples/local-search-validation.json`。此文件记录公网测试失败，不隐藏失败结果。上一版 9,640 token 实验使用的是冻结输入，不能作为新增搜索模块后的整个项目 token 数。

后续质量测试：15 条人工指定查询各重复 5 次。函数名/类名和英文功能描述分别 5/5 命中目标文件，但均只有 3/5 的返回片段保留指定关键代码；纯中文功能查询 0/5 命中目标实现。测试暴露的异常已修复，回归增加到 32 项通过，但检索质量尚未通过完整替代验收。详见 `experiments/search_quality/REPORT.md` 和逐条原始数据。返回片段不完整或未命中时，仍需读原文件或使用其他检索路径。
